# Extent — исходники расширений по контрагентам

Канон имён папок = `C:\Users\Admin\Desktop\расширения\<Контрагент>`.

## Структура

```text
Extent/
  <Контрагент УТ>/          # как на Desktop
    <ИмяРасширения>/        # XML-исходники CFE/EPF/ERF
  _неразнесено/             # контрагент не определён
```

Контрагенты УТ в workspace:

| Папка | Desktop |
|---|---|
| `УДАЧА УТ` | `…\расширения\УДАЧА УТ` |
| `ИмпортПро УТ` | `…\расширения\ИмпортПро УТ` |
| `ГЛОБАЛ УТ` | `…\расширения\ГЛОБАЛ УТ` |
| `Макухины УТ` | `…\расширения\Макухины УТ` |
| `ЭлектроСила УТ` | `…\расширения\ЭлектроСила УТ` |

## Сдача версии

`Desktop\расширения\<Контрагент>\<Имя>_<версия>.cfe|.epf`

## Memory Bank

`memory-bank/contractors/<Контрагент>/` — **новая задача: сначала спросить контрагента**.

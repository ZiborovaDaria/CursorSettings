# Extent — исходники расширений по контрагентам

Канон имён папок = `Desktop\расширения\<Контрагент>`.

```text
Extent/
  <Контрагент>/            # как на Desktop
    <ИмяРасширения>/       # XML-исходники CFE/EPF/ERF
  _неразнесено/            # контрагент не определён
```

Подставьте таблицу контрагентов проекта:

| Папка Extent | Desktop |
|---|---|
| `…` | `…\расширения\…` |

## Сдача версии

`Desktop\расширения\<Контрагент>\<Имя>_<версия>.cfe|.epf|.erf`

## Memory Bank

`memory-bank/contractors/<Контрагент>/` — **новая задача: сначала спросить контрагента**.

Подробности: `docs/EXTENT_CONTRACTORS.md` в пакете CursorSettings.

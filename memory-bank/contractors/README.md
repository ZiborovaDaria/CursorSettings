# Contractors — Memory Bank (шаблон)

Задачи ведутся **в разрезе контрагентов** Desktop:

`memory-bank/contractors/<имя как на Desktop>/`

| Файл | Назначение |
|---|---|
| `tasks.md` | задачи контрагента |
| `activeContext.md` | текущий фокус |
| `progress.md` | лог |

Корень `memory-bank/tasks.md` — только **индекс** и активный контрагент.

## Новая задача — обязательно спросить контрагента

Перед записью задачи в Memory Bank **сначала уточни у пользователя**, к какому контрагенту она относится.

1. Канон имён — папки `Desktop\расширения\<Контрагент>\` (путь пользователя локальный).
2. Если контрагент неясен — **не пиши** активную задачу; задай вопрос.
3. Неизвестный контрагент → `_неразнесено`.
4. После ответа: `contractors/<Контрагент>/tasks.md` + индекс в корне `tasks.md`.
5. Исключение: консультация без записи в MB.

> К какому контрагенту относится задача? (имя папки как на Desktop, или `_неразнесено`)

## Связь с Extent

Исходники CFE/EPF/ERF: `Extent/<Контрагент>/<Имя>/` — см. `docs/EXTENT_CONTRACTORS.md`.
